# GoWin Sportsbook

A full-stack sports betting platform (GoWin RDC) built as a pnpm monorepo.

## Stack

- **Frontend**: React + Vite + Tailwind CSS (`artifacts/gowin`)
- **Backend**: Express 5 + Drizzle ORM (`artifacts/api-server`)
- **Database**: PostgreSQL (Replit managed, `DATABASE_URL` runtime secret)
- **Payments**: PawaPay mobile money integration
- **Sports data**: AllSportsAPI
- **Lottery**: APIVerve + web scrapers

## How to run

Both workflows must be running:

- **`artifacts/api-server: API Server`** — builds then starts the API on port 8080
- **`artifacts/gowin: web`** — Vite dev server on port 5000 (preview pane)

After any source changes to `artifacts/api-server/src/`, rebuild before restarting:
```
cd artifacts/api-server && pnpm run build
```

## Libs (workspace packages)

| Package | Path | Purpose |
|---|---|---|
| `@workspace/db` | `lib/db` | Drizzle schema + DB client |
| `@workspace/api-zod` | `lib/api-zod` | Zod schemas shared with server |
| `@workspace/api-spec` | `lib/api-spec` | OpenAPI spec (generated) |
| `@workspace/api-client-react` | `lib/api-client-react` | React Query hooks (generated by Orval) |

## Required secrets

| Secret | Notes |
|---|---|
| `DATABASE_URL` | Runtime-managed by Replit |
| `SESSION_SECRET` | JWT signing secret (set in Replit Secrets) |
| `APIVERVE_KEY` | Optional — enables automated lottery result sync |
